# 我的书架 · My Bookshelf

一个纯前端的个人书架应用。书籍以木质书架的形式展示，可以记录阅读状态、阅读进度、评分和标签。

## 功能

- 将书籍分为「在读」「已读」「想读」三层书架。
- 添加、编辑和删除书籍，删除后可以撤销。
- 为在读书籍记录 0–100% 的阅读进度，并在编辑窗口中使用 `−5%` / `+5%` 快速调整。
- 为已读书籍记录 1–5 星评分，也可以选择「暂未评分」。
- 按书名、作者或标签实时搜索，并支持一键清空搜索。
- 在电脑上拖动书脊即可切换阅读状态。
- 显示藏书总数、各状态数量和平均评分。
- 导出 JSON 备份，导入时支持合并或替换。
- 导入前自动保留当前书架，可从页脚恢复上一次导入前的数据。
- 适配手机屏幕，支持键盘焦点和基本的无障碍提示。

## 使用方法

### 直接打开

双击 `index.html` 即可使用。也可以把项目放到任意静态网站托管服务上。

### 使用本地开发服务器

如果希望通过本地服务器运行，可以在项目目录执行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 数据说明

书籍默认保存在当前浏览器的 `localStorage` 中，存储键为 `bookshelf.books.v1`。数据不会自动同步到其他浏览器或设备，建议定期点击「导出」保存 JSON 备份。

导入文件必须是书籍数组，每本书至少包含以下字段：

```json
[
  {
    "name": "示例书名",
    "author": "示例作者",
    "status": "reading",
    "progress": 25,
    "rating": 0,
    "tags": ["示例", "阅读"]
  }
]
```

`status` 可使用以下值：

- `reading`：在读
- `finished`：已读
- `want`：想读

导入时会检查书名、状态、进度、评分和标签格式。无效文件不会修改当前书架；合并模式会按照“书名 + 作者”跳过重复书籍。
